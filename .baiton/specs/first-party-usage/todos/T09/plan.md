1. Ground truth to code against (read-only)

   The webview must consume exactly the protocol already in src/usage/protocol.ts and src/usage/model.ts (do NOT change them). Host->webview messages: {type:'readings', rows: UsageViewRow[], now:number} and {type:'state', state:{refreshing:boolean, trusted:boolean, refreshIntervalSeconds:number, now:number}}. Webview->host: {type:'ready'} and {type:'refresh'} only (anything else is dropped by parseUsageWebviewMessage). UsageWindow = {id, label, usedPercent?, raw?:{used?,limit?,remaining?,unit?}, resetsAt?, scope?:{model?,plan?}, provenance:'provider-reported'|'baiton-derived'}. UsageSource = {mechanism:'cli-command'|'cli-server'|'cli-files'|'provider-endpoint', detail, provenance, readAt}. 3. Create media/usage.js — host-free formatting mirror block

   `// @ts-check` header comment naming spec first-party-usage T09 and stating it consumes src/usage/protocol.ts messages. Wrap in `(function () { 'use strict'; ... })();`. Before the acquireVsCodeApi guard define pure, total (never-throwing) helpers with no DOM access, and export them as `window.baitonUsageView = { TOOL_ORDER, TOOL_LABELS, MECHANISM_LABELS, formatAge, formatReset, formatRaw, windowView, cardView }`:
   - `TOOL_ORDER = ['claude','codex','antigravity','opencode-go']`, `TOOL_LABELS` and `MECHANISM_LABELS` mirroring model.ts verbatim.
   - `formatAge(ms)`: <60s 'just now'; <60m 'N min ago'; <24h 'N h ago'; else 'N d ago'; non-finite/negative -> ''.
   - `formatReset(resetsAt, now)`: undefined/non-finite -> ''; past -> 'resets now'; else 'resets in Xh Ym' (or 'Xd Yh' >= 24h, 'Ym' < 1h) plus local clock via `new Date(resetsAt).toLocaleString()` in parentheses (keep the toLocaleString part out of what tests compare, e.g. return {relative, absolute}).
   - `formatRaw(raw)`: joins only present numbers, e.g. '12 / 50 requests used', '38 requests remaining'; uses `unit` when present; returns '' when raw is missing/empty. Never invents a percent from raw numbers.
   - `windowView(w, now)` -> {label, scopeText ('model: X · plan: Y' from scope, '' if none), hasBar: typeof w.usedPercent === 'number' && isFinite, remainingPercent (100 - clamp(usedPercent,0,100), only when hasBar), figure ('NN% remaining' when hasBar else formatRaw(w.raw) else 'No figure reported'), resetText, derived: w.provenance === 'baiton-derived'}.
   - `cardView(row, now)` -> {tool, label, refreshing, status: 'loading' when row.reading undefined else reading.status, badge text ('Loading…' / 'OK' / 'Stale' / 'Unavailable'), tier ('' if none), windows: windowView[] (empty for unavailable/loading), reason (stale: 'Last read failed: ' + reason; unavailable: reason; else ''), ageText (stale/ok: formatAge(now - source.readAt) — stale cards say 'Showing data from <age>'), sourceLine (ok/stale: MECHANISM_LABELS[mechanism] + ' — ' + detail + ' · ' + ('Baiton-derived' | 'Provider-reported') + ' · read ' + ageText; unavailable with mechanism: 'Tried: ' + MECHANISM_LABELS[mechanism]; else ''), derived (true when source.provenance or any window provenance is 'baiton-derived', matching isBaitonDerived)}.
   All functions tolerate malformed input (missing fields, wrong types) by returning empty strings/false rather than throwing.

   Files: `media/usage.js`

## Risks

- The todo text in the brief is truncated after 'Render one card per tool in fixed order with:'; the card contents in this plan (label, status badge, tier, per-window bar-or-raw figure, reset, scope, stale age + reason, unavailable reason, source line with mechanism/detail/provenance/read age, Baiton-derived labelling, restricted-mode note, refreshing indicator) are inferred from the OVERVIEW and the existing protocol. A reviewer expecting a different field list may ask for adjustments.
- A nonce-only style-src (no 'unsafe-inline') blocks `style=` attributes and setAttribute('style'), but CSSOM assignment (el.style.width = ...) is allowed; the executor must set the bar width only via el.style, never via a style attribute string, or bars will silently render at 0 width.
- If the later provider todo copies configPanel.ts's renderHtml, it must substitute ${nonce}, ${cspSource} and ${baseUri}; usage.html must use exactly those placeholder spellings.
- Objects returned from vm.runInNewContext have foreign prototypes; assert.deepStrictEqual against host-realm objects fails unless results are JSON round-tripped first.
- Theme variables such as --vscode-testing-iconPassed may be absent in some themes; always give a var(--vscode-foreground) fallback so text stays visible.
- The bar shows REMAINING percent (100 - usedPercent); mixing used vs remaining between bar and figure text would mislead. Bars must never be computed from raw numbers (barPercent in model.ts only uses usedPercent).

## Risks

- Hook trust is the likely blocker: codex 0.154.0 stores `HookStateToml { enabled, trusted_hash }` and ships `--dangerously-bypass-hook-trust`, so an inline `-c hooks…` hook may simply not run until a trust entry is persisted in `$CODEX_HOME`. `CodexAdapter.launch()` is pure and writes nothing, and the bypass flag is on the never-emit list (class doc degrade 6), so this outcome means Branch B. Do not 'fix' it by emitting the bypass flag or by writing a config file from the adapter.
- `-c key=value` parses the value as TOML and silently falls back to a literal raw string when the parse fails (see `tomlQuote`'s doc comment in src/adapter/codex.ts), so a malformed inline hooks value can look accepted while doing nothing. Use `--strict-config` and a hook that writes a log file to distinguish 'accepted and ran' from 'silently ignored'.
- The probe is easiest through `codex exec`, but Baiton launches the interactive form (class doc degrade 2). Behaviour verified only under `exec` must be recorded as such; claiming interactive parity without observing it would put an unverified claim in the README and ship wiring the probe did not justify.
- `codex exec` may require authentication. If it cannot run, the affected legs are **unverified** and the todo ships Branch B with that stated — inferring codex behaviour from the claude probe is not acceptable.
- The relay hook must block until the user answers (claude's blocks up to 600 s). If codex enforces a shorter hook timeout, the wiring must degrade to codex's own prompt on expiry, never to a silent allow; record the observed limit rather than assuming 600 s is accepted.
- A relay pair appended after `--` would be consumed as part of the prompt. It must go before the separator, and the `resume --last` branch (which emits no `--` and drops the prompt) needs its own test so the placement is not silently branch-specific.
- Editing src/adapter/permissions.ts (Branch A) touches a file shared with the claude relay; keep the codex constants separate rather than parameterising claude's, so test/adapter.claude.test.ts's pins on CLAUDE_RELAY_HOOK_SCRIPT/MATCHER/TIMEOUT stay valid.
